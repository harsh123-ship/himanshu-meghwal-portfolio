# Himanshu Meghwal | Professional Portfolio

A modern professional portfolio website built using HTML, CSS, JavaScript and Python Flask.

## About

Himanshu Meghwal is a professional associated with Security Number Plate and RTO-related work, with approximately 2.5 years of experience.

## Features

- Modern responsive portfolio design
- Professional profile section
- Career and experience details
- HSRP and RTO-related expertise
- Contact and WhatsApp integration
- Python Flask backend
- SQLite database
- Visitor tracking system
- Real-time analytics dashboard
- Daily, weekly and monthly statistics

## Technologies

- HTML5
- CSS3
- JavaScript
- Python
- Flask
- SQLite
- Chart.js

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open:

http://127.0.0.1:5000

Analytics Dashboard:

http://127.0.0.1:5000/dashboard
